## Magnetic Force Between Two Balls ( [LeetCode - 1552](https://leetcode.com/problems/magnetic-force-between-two-balls/) )

### Problem

You are given an array position containing the positions of holes. There are m balls. Place the balls into the holes so that the minimum distance between any two balls is maximized. Return the maximum possible minimum distance.

### Examples

- Example 1:

  - Input: position = [1,2,3,4,7], m = 3
  - Output: 3

- Example 2:

  - Input: position = [5,4,3,2,1], m = 2
  - Output: 4

### Constraints

- 2 <= position.length <= 10^5
- 1 <= position[i] <= 10^9
- 2 <= m <= position.length
