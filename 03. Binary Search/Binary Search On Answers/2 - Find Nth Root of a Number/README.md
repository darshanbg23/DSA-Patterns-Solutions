## Find Nth Root of a Number

### Problem

Given two integers x and n, find the integer value of the n-th root of x, rounded down to the nearest integer. Return the largest integer y such that y^n <= x.

### Examples

- Example 1:

  - Input: x = 16, n = 2
  - Output: 4

- Example 2:

  - Input: x = 27, n = 3
  - Output: 3

### Constraints

- 1 <= x <= 10^9
- 1 <= n <= 20
