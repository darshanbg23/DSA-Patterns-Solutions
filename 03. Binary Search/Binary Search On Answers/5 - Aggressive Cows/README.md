## Aggressive Cows

### Problem

You are given a sorted array of positions of stalls and an integer k. Place k cows in the stalls such that the minimum distance between any two cows is as large as possible. Return the maximum possible minimum distance.

### Examples

- Example 1:

  - Input: stalls = [1,2,4,8,9], k = 3
  - Output: 3

- Example 2:

  - Input: stalls = [1,2,3,4,7,8,9], k = 3
  - Output: 4

### Constraints

- 2 <= stalls.length <= 10^5
- 1 <= stalls[i] <= 10^9
- 2 <= k <= stalls.length
