## Find Square Root of a Number ( [LeetCode - 69](https://leetcode.com/problems/sqrtx/) )

### Problem

Given a non-negative integer x, compute and return the square root of x rounded down to the nearest integer. The result is an integer and should be the largest integer y such that y * y <= x.

### Examples

- Example 1:

  - Input: x = 4
  - Output: 2

- Example 2:

  - Input: x = 8
  - Output: 2

### Constraints

- 0 <= x <= 2^31 - 1
