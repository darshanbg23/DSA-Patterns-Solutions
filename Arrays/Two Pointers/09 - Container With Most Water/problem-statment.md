## Container With Most Water ( [LeetCode - 11](https://leetcode.com/problems/container-with-most-water/) )

### Problem

You are given an array of heights representing vertical lines. Find two lines that together with the x-axis form a container with the maximum possible area.

### Examples

- Example 1:

  - Input: height = [1,8,6,2,5,4,8,3,7]
  - Output: 49

- Example 2:

  - Input: height = [1,1]
  - Output: 1

### Constraints

- n == height.length
- 2 <= n <= 10^5
- 0 <= height[i] <= 10^4
