## 3Sum Closest ( [LeetCode - 16](https://leetcode.com/problems/3sum-closest/) )

### Problem

Given an integer array and a target value, find the triplet whose sum is closest to the target and return that sum.

### Examples

- Example 1:

  - Input: nums = [-1,2,1,-4], target = 1
  - Output: 2

- Example 2:

  - Input: nums = [0,0,0], target = 1
  - Output: 0

### Constraints

- 3 <= nums.length <= 500
- 1000 <= nums[i] <= 1000
- 10^4 <= target <= 10^4
