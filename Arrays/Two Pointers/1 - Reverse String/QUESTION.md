# Reverse String ( [LeetCode - 344](https://leetcode.com/problems/reverse-string/) )

## Problem

Write a function that reverses a string by modifying the input array of characters in place.

## Examples

Example 1:

Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]

Example 2:

Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]

## Constraints

- 1 <= s.length <= 10^5
- s[i] is a printable ASCII character.
