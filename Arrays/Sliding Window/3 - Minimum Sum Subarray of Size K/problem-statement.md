## Minimum Sum Subarray of Size K 

### Problem

Given an integer array nums and a positive integer k, find the minimum sum of any contiguous subarray of length k.

### Examples

- Example 1:

  - Input: nums = [2, 1, 5, 1, 3, 2], k = 3
  - Output: 3

- Example 2:

  - Input: nums = [1, 2, 3, 4, 5], k = 2
  - Output: 3

### Constraints

- 1 <= k <= nums.length
- 1 <= nums[i] <= 10^5
- 1 <= nums.length <= 10^5
