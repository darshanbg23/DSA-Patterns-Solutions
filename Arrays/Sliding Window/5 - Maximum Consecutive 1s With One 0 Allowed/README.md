## Maximum Consecutive 1s With One 0 Allowed ( [LeetCode - 487](https://leetcode.com/problems/max-consecutive-ones-ii/) )

### Problem

Given a binary array nums, find the maximum number of consecutive 1s you can get by flipping at most one 0 to 1.

### Examples

- Example 1:

  - Input: nums = [1,0,1,1,1,0,1]
  - Output: 5

- Example 2:

  - Input: nums = [1,0,1,1,1]
  - Output: 4

### Constraints

- 1 <= nums.length <= 10^5
- nums[i] is either 0 or 1
