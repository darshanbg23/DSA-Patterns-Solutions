## Trapping Rain Water ( [LeetCode - 42](https://leetcode.com/problems/trapping-rain-water/) )

### Problem

Given an elevation map represented by non-negative integers, compute how much rainwater can be trapped between the bars.

### Examples

- Example 1:

  - Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
  - Output: 6

- Example 2:

  - Input: height = [4,2,0,3,2,5]
  - Output: 9

### Constraints

- n == height.length
- 1 <= n <= 2 * 10^4
- 0 <= height[i] <= 10^5
