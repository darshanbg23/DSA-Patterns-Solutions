## 3Sum ( [LeetCode - 15](https://leetcode.com/problems/3sum/) )

### Problem

Given an integer array, return all unique triplets whose sum is zero.

### Examples

- Example 1:

  - Input: nums = [-1,0,1,2,-1,-4]
  - Output: [[-1,-1,2],[-1,0,1]]

- Example 2:

  - Input: nums = [0,1,1]
  - Output: []

- Example 3:

  - Input: nums = [0,0,0]
  - Output: [[0,0,0]]

### Constraints

- 3 <= nums.length <= 3000
- 10^5 <= nums[i] <= 10^5
