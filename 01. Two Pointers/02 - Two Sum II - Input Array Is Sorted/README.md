## Two Sum II - Input Array Is Sorted ( [LeetCode - 167](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/) )

### Problem

Given a sorted array of integers, find two indices whose values add up to a specific target value and return the indices as a 1-indexed array.

### Examples

- Example 1:

  - Input: numbers = [2,7,11,15], target = 9
  - Output: [1,2]

- Example 2:

  - Input: numbers = [2,3,4], target = 6
  - Output: [1,3]

- Example 3:

  - Input: numbers = [-1,0], target = -1
  - Output: [1,2]

### Constraints

- 2 <= numbers.length <= 3 * 10^4
- 1000 <= numbers[i] <= 1000
- numbers is sorted in non-decreasing order.
- 1000 <= target <= 1000
- The tests are generated such that there is exactly one solution.
