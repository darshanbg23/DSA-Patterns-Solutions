## Move Zeroes ( [LeetCode - 283](https://leetcode.com/problems/move-zeroes/) )

### Problem

Move all zero values to the end of the array while maintaining the relative order of the non-zero elements.

### Examples

- Example 1:

  - Input: nums = [0,1,0,3,12]
  - Output: [1,3,12,0,0]

- Example 2:

  - Input: nums = [0]
  - Output: [0]

### Constraints

- 1 <= nums.length <= 10^4
- 2^31 <= nums[i] <= 2^31 - 1
