## Longest Subarray With Sum ≤ K ( [LeetCode - 325](https://leetcode.com/problems/maximum-size-subarray-sum-equals-k/) )

### Problem

Given an array nums and an integer k, find the length of the longest subarray whose sum is less than or equal to k.

### Examples

- Example 1:

  - Input: nums = [3,1,1,1], k = 5
  - Output: 3

- Example 2:

  - Input: nums = [1,2,3,4,5], k = 7
  - Output: 3

### Constraints

- 1 <= nums.length <= 10^5
- 10^5 <= nums[i] <= 10^5
- 10^9 <= k <= 10^9
