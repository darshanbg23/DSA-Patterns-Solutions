## Maximum Average Subarray I ( [LeetCode - 643](https://leetcode.com/problems/maximum-average-subarray-i/) )

### Problem

You are given an integer array nums and an integer k. Find a contiguous subarray of length k that has the maximum average value.

### Examples

- Example 1:

  - Input: nums = [1,12,-5,-6,50,3], k = 4
  - Output: 12.75000

- Example 2:

  - Input: nums = [5], k = 1
  - Output: 5.00000

### Constraints

- n == nums.length
- 1 <= k <= n <= 10^5
- 10^4 <= nums[i] <= 10^4
