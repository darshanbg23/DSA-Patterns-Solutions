## Max Consecutive Ones III ( [LeetCode - 1004](https://leetcode.com/problems/max-consecutive-ones-iii/) )

### Problem

Given a binary array nums and an integer k, return the length of the longest subarray containing at most k zeros.

### Examples

- Example 1:

  - Input: nums = [1,1,1,0,0,0], k = 2
  - Output: 5

- Example 2:

  - Input: nums = [0,0,1,1,1,0,0], k = 0
  - Output: 3

### Constraints

- 1 <= nums.length <= 10^5
- nums[i] is either 0 or 1
- 0 <= k <= nums.length
