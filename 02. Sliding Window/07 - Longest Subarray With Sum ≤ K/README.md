## Longest Subarray With Sum ≤ K

### Problem

Given an array `nums` containing non-negative integers and an integer `k`, find the length of the longest contiguous subarray whose sum is less than or equal to `k`.

### Examples

- Example 1:

  - Input: nums = [3,1,1,1], k = 5
  - Output: 3

- Example 2:

  - Input: nums = [1,2,3,4,5], k = 7
  - Output: 3

### Constraints

- 1 <= nums.length <= 10^5
- 10^5 <= nums[i] <= 10^5
- 10^9 <= k <= 10^9
