## Maximum Sum Subarray of Size K ( [GFG](https://www.geeksforgeeks.org/problems/max-sum-subarray-of-size-k5313/1) )

### Problem

Given an array of integers arr[] and a number k. Return the maximum sum of a subarray of size k.

### Examples

- Example 1:

  - Input: arr[] = [100, 200, 300, 400], k = 2
  - Output: 700

- Example 2:

  - Input: arr[] = [1, 4, 2, 10, 23, 3, 1, 0, 20], k = 4
  - Output: 39

### Constraints

- arr.size() ≤ 10^6
- 0 ≤ arr[i] ≤ 10^6
- 1 ≤ k ≤ arr.size()
