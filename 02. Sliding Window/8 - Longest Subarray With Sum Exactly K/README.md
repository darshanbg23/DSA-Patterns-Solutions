## Longest Subarray With Sum Exactly K ( [LeetCode - 560](https://leetcode.com/problems/subarray-sum-equals-k/) )

### Problem

Given an array nums and an integer k, return the length of the longest subarray whose sum is exactly k.

### Examples

- Example 1:

  - Input: nums = [1, 2, 3, 1, 1, 1, 1], k = 3
  - Output: 3

- Example 2:

  - Input: nums = [1, -1, 5, -2, 3], k = 3
  - Output: 4

### Constraints

- 1 <= nums.length <= 10^5
- 10^9 <= nums[i] <= 10^9
- 10^9 <= k <= 10^9
