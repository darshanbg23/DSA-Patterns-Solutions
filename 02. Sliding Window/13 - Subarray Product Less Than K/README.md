## Subarray Product Less Than K ( [LeetCode - 713](https://leetcode.com/problems/subarray-product-less-than-k/) )

### Problem

Given an integer array nums and an integer k, return the number of contiguous subarrays where the product of all the elements in the subarray is strictly less than k.

### Examples

- Example 1:

  - Input: nums = [10,5,2,6], k = 100
  - Output: 8

- Example 2:

  - Input: nums = [1,2,3], k = 0
  - Output: 0

### Constraints

- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 1000
- 0 <= k <= 10^9
