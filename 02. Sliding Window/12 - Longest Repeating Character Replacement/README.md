## Longest Repeating Character Replacement ( [LeetCode - 424](https://leetcode.com/problems/longest-repeating-character-replacement/) )

### Problem

You are given a string s and an integer k. You can choose any character and change it to any other uppercase English character. Return the length of the longest substring that contains the same character after at most k replacements.

### Examples

- Example 1:

  - Input: s = "ABAB", k = 2
  - Output: 4

- Example 2:

  - Input: s = "AABABBA", k = 1
  - Output: 4

### Constraints

- 1 <= s.length <= 10^5
- s consists of uppercase English letters
- 0 <= k <= s.length
